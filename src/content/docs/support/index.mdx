## Choose the support route

- **New project or access request:** submit the
  [Spike Service Desk form](https://tue.topdesk.net/tas/public/ssp/content/serviceflow?unid=93e8b8b00471499593597171aaddaf34).
- **Existing project:** use the SCC support channel named during onboarding.
  Keep the project name and original request reference in the conversation.
- **You no longer know the project channel:** open the
  [TU/e Service Desk](https://tue.topdesk.net/tas/public/ssp/) and identify the
  service as **Spike / SCC research computing**.

Researchers should not contact infrastructure suppliers directly. SCC owns
platform diagnosis and any escalation to MDCS, NVIDIA, or another vendor.

Start with the matching [troubleshooting entry](/troubleshooting/) and include:

- project and workload name;
- approximate time and current workload state;
- image tag and selected compute-resource preset;
- a short, safe log excerpt and actions already tried.

Do not include passwords, private keys, access tokens, personal contact details,
or sensitive dataset contents.

## Report an urgent platform problem

State whether the problem affects one workload, one project, or several
projects. Include the first observed time and a safe way to reproduce the
symptom. If the platform is unavailable, submit the Service Desk request first
and then use the onboarding channel to share the request number and impact.
