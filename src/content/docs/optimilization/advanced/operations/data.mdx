## Method interface for writing a CUDA/C++ extension

Writing a PyTorch extension starts at C++ level with a CUDA kernel and a host launch function.
The CUDA kernel takes in flat array pointers pointing to a base memory location in vRAM.
The flat array pointers denote the base memory location of the tensors involved in the particular calculation of interest.
Additional size variables can be provided to the CUDA kernel, provided that the size variables are derived within the scope of the host launch function.
For example, the tensor dimension sizes can be retrieved from the ***Torch::tensor*** class with the ***size()*** method.
Within the scope of the CUDA kernel, the tensor calculation output is written to the relevant pointer location which denotes a memory offset wrt. the base memory location:

```
#include <torch/extension.h>
#include <cuda_runtime.h>


#define TILE_SIZE 32


// Forward matrix (2d tensor) multiplication kernel
__global__ void matmul_kernel(const float* __restrict__ A,
                              const float* __restrict__ B,
                              float* __restrict__ C,
                              int M, int K, int N) {

...

}


// Host launch function
torch::Tensor matmul(torch::Tensor A, torch::Tensor B) {
  int M = A.size(0);
  int K = A.size(1);
  int N = B.size(1);

  auto C = torch::empty({M, N}, torch::dtype(torch::kFloat32).device(A.device()));

  dim3 threads(TILE_SIZE, TILE_SIZE);
  dim3 blocks((N + TILE_SIZE - 1) / TILE_SIZE, (M + TILE_SIZE - 1) / TILE_SIZE);

  // Shared memory: 4 tiles for forward kernel.
  size_t shared_mem_size = 4 * TILE_SIZE * TILE_SIZE * sizeof(float);
  
  matmul_kernel<<<blocks, threads, shared_mem_size>>>(
      A.data_ptr<float>(), B.data_ptr<float>(), C.data_ptr<float>(), M, K, N);
  
  return C;
}
```

When writing a PyTorch extension, it is important to remember that you need to write kernels and launch functions which together make up the entire automatic differentation procedure for the tensor operation.
For a gemm, this means that CUDA kernels and host launch functions need to be provided for the partial gradients wrt. both A and B.
These partial derivatives are respectively: grad_A = grad_output * B^T, grad_B = A^T * grad_output.
For more information regarding known combinations of forward and partial derivative backward combinations, we refer to Bob Carpenter's [automatic differentation handbook](https://github.com/bob-carpenter/ad-handbook).
