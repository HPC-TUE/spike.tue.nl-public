| Term | Meaning |
| --- | --- |
| Run:ai project | The access and resource boundary for members, workloads, storage, and policies. |
| Workload | A submitted unit of work, such as a workspace, training job, or inference service. |
| Interactive workspace | A temporary shell or notebook workload for exploration and debugging. |
| Training workload | A non-interactive workload with a command, logs, and completion state. |
| Inference workload | A serving workload that keeps a model endpoint available to authorized clients. |
| Environment | Reusable runtime configuration, including an image and settings. |
| Compute resource | A platform-approved allocation preset for GPU, CPU, and memory. |
| Harbor | The registry that stores project-scoped container images. |
| Data source | Storage attached to a project or workload. |
| Persistent volume | Storage intended to survive workload restarts according to project policy. |
| Ephemeral volume | Disposable storage that disappears with its workload. |
| Preemptible | Eligible to be stopped for higher-priority work; requires checkpointing and retry-safe design. |
