This privacy statement describes how Eindhoven University of Technology (TU/e)
handles information when you visit and use the public Spike documentation
website (`docs.spike.tue.nl`).

## Scope of this website

This site is a static, public documentation resource operated by the TU/e
Supercomputing Center (SCC). Its purpose is to provide researchers and staff with
operational guidance, tutorials, and reference materials for research workloads
on Spike.

## Information we collect

This documentation site does not require user registration and does not collect
personal data directly:

- **No user accounts:** You do not need to create an account or sign in to read
  this documentation.
- **No interactive forms:** There are no contact forms, comment fields, or
  submission endpoints hosted on this site. Service requests and support tickets
  are handled through the external [TU/e Service Desk](https://tue.topdesk.net/tas/public/ssp/).
- **Search indexing:** The on-site documentation search is powered by Pagefind,
  a client-side search library that runs entirely in your browser using pre-built
  static indexes. Search queries are not sent to or stored on an external search
  server.

## Cookies and local storage

This website does not set tracking, profiling, or third-party advertising
cookies.

The site uses your browser's local storage (`localStorage`) solely for the
technical operation of interface preferences:

- `starlight-theme`: stores your chosen visual appearance (`light`, `dark`, or
  system default) so your preference persists across page navigation.

This technical storage contains no identifying information and is not shared
with external services.

## External services and hosting

This public documentation is statically generated and hosted via GitHub Pages.
When you visit the site, standard technical web server logs (such as IP address,
browser user-agent, and access timestamp) may be processed by the hosting
infrastructure to deliver requested assets securely and reliably.

External links to TU/e platforms (such as the Run:ai cluster interface, Harbor
registry, GitLab, and TOPdesk) operate under their respective institutional
access and security controls.

## TU/e institutional privacy policy

For general information on how Eindhoven University of Technology processes
personal data, your rights under the General Data Protection Regulation (GDPR),
and contact information for the TU/e Data Protection Officer, consult the
[TU/e Privacy Statement](https://www.tue.nl/en/our-university/about-the-university/privacy-statement/).
