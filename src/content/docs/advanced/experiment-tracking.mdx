Configure experiment tracking through the approved secret mechanism. Keep
tokens out of Containerfiles, command lines, source control, and captured logs.

Record the Run:ai project, image tag, workload name, code revision, dataset
version, and tracking run identifier together so a result can be reproduced.
External scheduler examples in the source material are Historical; translate
them to a Run:ai workload rather than copying their commands.
