## Your first successful workload

1. Request access and confirm that your Run:ai project and Harbor project are visible.
2. Build a small, versioned image with Podman and publish it to Harbor.
3. Create a training workload in Run:ai with a modest compute-resource preset.
4. Confirm the workload reaches **Running**, inspect its logs, and stop or delete it when finished.

:::tip
For the shortest path, start with [Start here](/start-here/), then follow the
links at the bottom of each guide. Use [Troubleshooting](/troubleshooting/) as
soon as a workflow does not behave as expected.
:::

## Service boundaries

Spike provides the platform for workloads, scheduled compute, project-scoped
data sources, and container environments. Your project determines what you can
run and access. The public documentation deliberately does not expose
operational credentials, internal identifiers, or project-administration
procedures.
